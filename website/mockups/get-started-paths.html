  4. IV

    Hand it main, last

    Do your own setup first, then end main with Moonframe: run() holds the main thread until the window closes. Your Rust publishes data as a provider, plain or async on tokio; Luau draws it.

    Sync · src/main.rs
    use moonframe::{Data, Handle, Moonframe, Native};

#[derive(Default)]
struct Vault { /* your state */ }

impl Native for Vault {
    fn tick(&mut self, host: &Handle) {
        host.publish_json(&self.summary());
    }
    fn receive(&mut self, host: &Handle, _from: &str, msg: Data) {
        /* a mod sent { open = id } */
    }
}

fn main() -> std::process::ExitCode {
    // 1. Your setup first: config, logging, CLI flags.
    env_logger::init();

    // 2. Moonframe last: run() takes the main thread
    //    and returns when the window closes.
    Moonframe::new("my-app")
        .app_dir(concat!(env!("CARGO_MANIFEST_DIR"), "/app"))
        .native("vault", Vault::default)
        .run()
}
    Async · tokio
    use moonframe::{AsyncNative, Data, Handle, Moonframe};

#[derive(Default)]
struct Weather { client: reqwest::Client }

impl AsyncNative for Weather {
    async fn tick(&mut self, host: &Handle) {
        match self.client.get(URL).send().await {
            Ok(r) => host.publish_json(&r.json().await.unwrap_or_default()),
            Err(e) => host.fail(e.to_string()),
        }
    }
}

#[tokio::main]  // run() reuses this multi-thread runtime
async fn main() -> std::process::ExitCode {
    // 1. Your setup first: pools and clients on tokio.
    let db = connect().await;

    // 2. Moonframe last. Providers and views share
    //    your runtime (moonframe::on_runtime in views).
    Moonframe::new("my-app")
        .app_dir(concat!(env!("CARGO_MANIFEST_DIR"), "/app"))
        .native_async("weather", Weather::default)
        .run()
}

Start a new app

Clone the starter, rename it, and change it live, by hand or with an agent.

git clone https://github.com/moonframehq/moonframe my-app
cd my-app
mise install   # Rust, Zig
just run

Then ask your agent for anything; it changes live. Needs rustup, just, mise.

A Rust project

Add it to your crate

Keep your code and your repository. Moonframe becomes the window; your Rust feeds it.

brew install moonframehq/tap/moonframe
moonframe init . --name my-app
cargo add moonframe \
  --git https://github.com/moonframehq/moonframe
cargo run

init writes app/, types and skills, and prints the main.rs to paste. Library guide.

Example: msgvault-moonframe, a mail archive reader →

Just want to use it

Install the app

No Rust needed. Ask an agent in your own folder to change anything; add mods and whole apps from git.

brew install moonframehq/tap/moonframe
open -a Moonframe
# an agent in a pane, in your folder:
moonframe pane new --agent claude \
  "add a clock to the status bar"
moonframe mod install owner/repo

Turn on Developer Mode in the app menu for Inspect Element. macOS 13+; Linux, Windows.
