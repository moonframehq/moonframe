Start / Introduction

Moonframe

A starter for native desktop apps whose whole window is written in Luau. Rust and GPUI draw it, check it, and keep it safe; every panel is a Luau file that reloads as you save, with its state kept.

$ git clone https://github.com/moonframehq/moonframe my-app
$ cd my-app
$ mise install   # Rust, and Zig for the Ghostty terminal
$ just run       # opens the window on app/
Quick start →Clone, run, edit a file, watch it change. Your first mod →State, init, update, view. Component catalogue →Every ui.* and use piece. Build an app →moonframe.toml, profiles, bundles.

A mod is one file

The shell (app/main.luau) places regions, and mods fill them. Mods talk with messages, like an Elm program.

return mod {
  region = "left",
  init = function(previous) return previous or { count = 0 } end,
  update = function(state, msg) if msg == "add" then state.count += 1 end end,
  view = function(state) return ui.button { "Add", msg = "add" } end,
}
Sandboxed by design. Luau has no files, network or process access. Anything that reaches the machine goes through a provider or an element the host owns.

Platforms

Developed on macOS. CI builds and tests on macOS, Linux (x86_64, ARM64) and Windows; releases ship with checksums, Sigstore signatures and GitHub attestations.
