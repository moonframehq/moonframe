One file per mod

Elm-shaped.
Hot-reloaded.

Each mod has its own state, init, update and view. Mods talk with messages. Save it, and it appears in its region.

-- app/mods/counter/main.luau
return mod {
  region = "left",
  init = function(previous)
    return previous or { count = 0 }
  end,
  update = function(state, msg)
    if msg == "add" then state.count += 1 end
  end,
  view = function(state)
    return ui.panel { title = "Counter",
      ui.text(`Clicked {state.count} times`),
      ui.button { "Add", msg = "add" } }
  end,
}
