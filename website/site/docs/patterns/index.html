From browsing to building

Take the pattern. Make it yours.

Components are the individual pieces. Patterns compose them with deliberate layout and visual hierarchy. Demos show complete applications.

1. Copy the pattern

Copy the Pattern source into components/<name>.luau in your app. Its dependencies are built-in Moonframe components.

2. Try the example

The Example tab is a complete mod with sample data, state and message handlers. Copy it into mods/example/main.luau and mount it in your shell with ui.mount "example".

3. Connect your data

Keep the component's styling hooks; replace the sample data and handle actions in your own mod.

Browse alongside your app

just patterns

In a Moonframe checkout, this opens the standalone native browser with live previews and source. It has its own identity and state.

Ship only what you use

The patterns Cargo feature enables a separate moonframe-patterns executable. It is off by default. The starter and apps using the library include neither this showcase nor its catalog; copy only the pattern files you need.
