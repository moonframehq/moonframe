# Welcome to Commonplace

Everything here is a plain markdown file in this folder, so Obsidian, git and any editor can open it too.

- **Inbox**: write anything there, newest at the top. Review it now and then: keep what matters, turn the rest into notes or tasks, let the rest sink.
- **Today**: a daily note in `journal/`, as an outline.
- **Notes**: your own pages. Link them with `[[double brackets]]`; links work both ways.
- **Wiki**: pages an AI agent keeps from the sources in `raw/` (see `AGENTS.md`).

Switch layouts in the View menu: Library, Journal or Workspace.
